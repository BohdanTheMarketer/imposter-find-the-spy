Висновки

Що працює і що ні

Працює
  • Онбординг — 91% прохідність
  • Replay серед гравців — 6.1 гри/user
  • Глибина сесії — 72+ події для активних
  • Checkout — 77% plan→result конверсія
  • Game completion — 73% стартувавших завершують
Не працює
  • 35% ніколи не грають — paywall блокує core loop
  • 87% закривають paywall без дії
  • purchase_result → paid: лише 4.3%
  • rate_us на 90% users — занадто рано
  • 1.3 сесії/user — слабке повернення
Рекомендації

Що змінити для кращого використання

  • 1 безкоштовна гра до paywall — підняти game_start з 65% до 80%+. Користувач має відчути fun перед запитом грошей.
  • Перенести rate_us після 2-ї гри — зараз 90% бачать запит до геймплею.
  • Розслідувати 23→1 purchase gap — чи це trial, sandbox, чи баг у revenue tracking. Без цього неможливо оцінити реальну монетизацію.
  • Soft paywall для 40 «незавершувачів» — дали game_start, але не game_end. Можливо, гра обривається через paywall mid-session.
  • Push повернення для 106 активних гравців — вони вже люблять продукт (6+ ігор). Нагадування «зібрати друзів» може підняти 1.3 → 2+ сесій.
  • Додати подію game_abandoned — зрозуміти, де саме 40 users відвалюються під час гри.
